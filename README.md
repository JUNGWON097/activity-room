# 액티비티룸

각자 플레이하고 기록으로 겨루는 미니게임 6종.

| 게임 | 기록 | 순위 |
|---|---|---|
| 🏹 바람 양궁 | 6발 합계 점수 | 높을수록 |
| 🤠 석양의 결투 | 5판 평균 반응속도(ms) | 낮을수록 |
| ⚽ 굴러라 공 | 버틴 시간(초) | 높을수록 |
| 🪜 계단 레이스 | 오른 계단 수 | 높을수록 |
| 🎫 티켓팅 체험 | 3회차 점수 합계(좌석 위치 + 속도) | 높을수록 |
| 💪 연타 줄다리기 | 10초 연타 횟수 | 높을수록 |

- 기록은 Firebase Firestore `arcade/{게임}/scores/{닉네임}`에 닉네임별 최고 기록 1건으로 저장된다.
- 파일을 고쳐 올릴 때는 모든 html · js의 `?v=숫자`를 함께 올린다(브라우저가 예전 파일을 쓰지 않게). `common.js` 주소는 모든 파일에서 같아야 한다.
- 주소 끝에 `?dev`를 붙이면 연습용 보관함(`arcade-dev`)에 저장돼 실제 랭킹에 섞이지 않는다.
